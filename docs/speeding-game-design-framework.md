# Speeding 游戏设计系统、缺口与平台归属

状态：Product Design Draft v0.1

## 1. 现有设计已经解决了什么

现有世界观、MVP 账本和 Agent 契约已经建立了三个可靠支点：

- **命题**：首富必须在三十天内同时放弃财富和实际控制权；
- **裁判**：净值、控制、合规、稳定和社会信用由确定性规则结算；
- **角色冲突**：不同顾问代表企业价值、员工、程序、公共安全、去权力和私人责任。

目前缺少的不是更多背景文字，而是连接这三个支点的“游戏发动机”：玩家持续行动的动力、
维持行动资格的压力、世界自主反应、承诺的不可逆性、信息发现、路线形成和失败推进。

## 2. 游戏的产品承诺

Speeding 不是“把数字点到零”的消费小游戏，而是：

> 玩家在一个会记忆、结盟、阻挠和重新定价其行为的社会系统中，尝试主动终结自己的财富与
> 权力，同时为由此产生的后果负责。

四个设计支柱：

1. **财富守恒**：钱不会因为按钮被按下而消失，只会转换形态、对象、责任和控制关系。
2. **世界反抗**：董事会、员工、监管、家族、市场和公众都有自身目标，不是玩家的菜单。
3. **关系即机制**：Agent 的信任、敌意、秘密、联盟和执行意愿真实改变可用方案。
4. **选择会留下制度**：最重要的结果不是花了多少钱，而是玩家离开后谁获得权力、承担责任。

## 3. 玩家动力

玩家动力不应只有倒计时，而应同时满足六种欲望：

| 动力 | 玩家体验 | 支撑系统 |
|---|---|---|
| 完成不可能任务 | 在 30 天内真正归零 | 净值/控制审计、倒计时、交割队列 |
| 战胜复杂系统 | 找到合法且可结算的组合方案 | 账本、产权、审批、容量和价格规则 |
| 塑造个人立场 | 决定什么代价可以接受 | 价值冲突、不可兼得指标、结局评价 |
| 经营人物关系 | 争取执行者、识破阻挠者 | 组织关系、信任、任务、会议和秘密 |
| 发现真相 | 查明公约、缺失十一秒和旧事故 | 调查行动、知情状态、证据链、私人事件 |
| 比较与复盘 | 看自己创造了怎样的退场方式 | 因果回放、路线标签、结局和排行榜 |

其中“查明真相”不应成为必须完成的唯一主线。玩家可以成功归零但未发现真相，也可以揭开
真相却未能归零；这会形成真正不同的故事，而不是同一剧情的不同对白。

## 4. 三层核心循环

### 4.1 短循环：一次决策，5–15 分钟

```text
读取晨报与人物态度
→ 询问、调查、谈判或下令
→ Agent 提出意见、反对或执行条件
→ 玩家确认 CanonicalAction
→ 规则结算即时结果并登记延迟后果
→ 世界传播、人物反应、关系和知情变化
```

### 4.2 中循环：一个游戏日，15–30 分钟

```text
晨间压力出现
→ 选择有限行动与会议资源
→ 推动或修订一项不可逆安排
→ 处理一项新危机或人物私事
→ 夜间结算、新闻和未解决矛盾升级
```

### 4.3 长循环：一局游戏，约 7–8 小时

```text
建立退场方案
→ 形成联盟和敌人
→ 承诺逐渐锁定路线
→ 外部系统开始反制
→ 真相与私人代价浮现
→ 最后阶段处理控制残留和交割
→ 午夜审计、制度遗产和人物结局
```

## 5. “生存”在 Speeding 中是什么

不建议加入普通生命值。Speeding 的生存是“继续拥有合法行动能力”，由四条生命线组成：

### 5.1 行动资格（Agency）

玩家是否仍有权签署、任命、撤销、谈判和处分资产。董事会罢免、监护程序、法院禁令或
账户冻结都会削弱行动资格。降至零不一定立即结束游戏，但玩家只能通过代理人或申诉推进。

### 5.2 合法性（Legitimacy）

合规度、证据完整性和公众可信度共同决定制度是否继续承认玩家的行动。违法不是高风险捷径，
而是可能让交易失效并把玩家送入“冻结与接管”路线。

### 5.3 系统连续性（Continuity）

集团承担能源、支付、通信等公共职能。稳定过低时，监管和组织将接管关键资产，玩家会失去
处置空间。它使“最快归零”与“安全归零”产生真实冲突。

### 5.4 时间窗口（Time）

玩家不仅消耗天数，还消耗审批窗口、市场窗口、对手耐心和人物承诺期限。最后一天无法突然
完成需要十天审批的行为。

财富不是生命值。它是玩家必须降低的目标，同时又是解决危机、补偿受害者和稳定系统的资源。
这种反向资源结构才是 Speeding 的核心张力。

## 6. 推动故事前进的底层机制

故事不能依赖叙事导演随意“发剧情”。应由六个机制共同推动：

### 6.1 压力时钟（Pressure Clocks）

每个重大矛盾拥有 0–4 或 0–6 格进度，例如：

- 董事会罢免；
- 监管接管；
- 员工不安；
- 市场挤兑；
- 家族诉讼；
- 旧事故曝光。

玩家行动、拖延和世界事件推进或回退时钟。填满时触发预先定义的制度后果，而不是只扣分。

### 6.2 承诺锁（Commitment Locks）

签署独立受托、公开披露、接受监管条件、向某一派系承诺等行为会关闭部分未来选项，同时开启
新的路线。玩家因此逐渐形成自己的故事，而不是到最后一刻仍能选择所有结局。

### 6.3 自主派系议程（Faction Agendas）

每个派系拥有目标、红线、资源、可见信息和下一步计划。即使玩家不行动，派系也会在预算内
推进议程。联盟只是暂时目标一致，不意味着人格合并或永久服从。

### 6.4 待办债务（Obligation Debt）

被搁置的承诺、调查、赔偿、员工安置和审批会积累责任。拖延不是空操作，而会提高成本、降低
信任或让他人抢先行动。

### 6.5 信息揭示（Discovery）

调查、关系信任、泄密和制度程序逐层开放事实。信息可以改变行动可用性、结算风险和人物立场，
而不只是解锁一段剧情文本。

### 6.6 不可逆结算（Irreversible Settlement）

已完成转让、公开证词、董事会表决和关系破裂不能免费读档式撤销。游戏可以允许玩家修复后果，
但必须通过新行动承担成本。

## 7. 玩家资源与行动经济

建议把玩家资源分成四类：

| 资源 | 用途 | 恢复方式 |
|---|---|---|
| 主要行动 | 发起出售、转让、重组、公开决定 | 每个游戏日刷新，不能购买无限次数 |
| 注意力 | 深入处理会议、人物私事、危机 | 休息、授权、缩小管理范围 |
| 政治/组织授权 | 推动需要他人执行的方案 | 谈判、让步、建立联盟、履行承诺 |
| 信息质量 | 降低行动歧义和规则风险 | 调查、审计、询问、交叉验证 |

金钱不购买平台 Token，也不能直接购买 Agent 忠诚。玩家可以花钱创造条件，但人物是否接受
仍由其利益、人格、关系和制度权限决定。

## 8. 世界模型

完整世界观需要的不只是百科设定，还要有可运转的实体与制度：

```text
人：玩家、家人、员工、顾问、受害者、官员、交易对手
组织：集团、子公司、董事会、工会、监管机构、基金会、媒体
资产：股份、私产、债权、知识产权、数据权、信托权益
权力：投票权、任免权、否决权、撤销权、声誉影响、代理关系
制度：法律辖区、审批、披露、税务、托管、公共服务义务
信息：世界事实、证据、谣言、秘密、公开记录、人物认知
时间：期限、审批期、市场窗口、会议和延迟结算
```

世界事实只有一份；人物认知、公开叙事和玩家所见可以不同。世界模型负责“什么是真的”，
Agent 负责“某个人如何理解并行动”，叙事层负责“玩家如何看到已经发生的事情”。

## 9. 事件内容结构

路线事件、人物私事和系统事件应共用一个内容契约：

```yaml
id: board-coup-ultimatum
kind: route                  # route | personal | systemic | ambient
chapter: pressure
preconditions: []
triggers: []
participants: []
knowledgeRequirements: []
pressureClockEffects: []
availableActions: []
commitmentLocks: []
immediateEffects: []
scheduledEffects: []
relationshipEffects: []
factRevelations: []
followups: []
cooldown: 0
expiry: null
directorTags: [governance, escalation]
```

四类事件承担不同职责：

- **系统事件**：由数值、时钟和制度规则触发，保证世界会动；
- **路线事件**：由玩家长期选择和承诺触发，形成分支；
- **人物私事事件**：由关系、记忆、秘密和个人目标触发，提供情感厚度；
- **环境事件**：低成本呈现世界反馈和节奏，不强迫作出重大选择。

“约 40 个事件”只是内容数量，不是完成标准。每个重大选择至少要有即时反应、延迟后果、人物
态度和制度影响中的两项，否则只是一次性文本卡片。

## 10. 叙事推进与 Director 边界

Narrative Director 只做选择和编排：

- 判断当前章节与节奏是否停滞；
- 从满足前置条件的事件模板中选择候选；
- 控制同类危机密度和角色曝光；
- 提醒未解决矛盾、人物弧光和伏笔；
- 在预算内触发环境事件或合法升级。

Director 不能：

- 创造账本中不存在的交易；
- 强迫 Agent 违背权限或已知信息；
- 跳过事件前置条件；
- 直接修改关系、情绪和世界指标；
- 为追求戏剧性篡改确定性结算。

真正推动故事的是世界状态、压力时钟、派系议程和玩家承诺；Director 负责让这些后果以合适
节奏进入玩家视野。

## 11. 失败、续玩与结局

失败分成三层：

1. **行动失败**：某项交易被拒绝或延迟，故事继续并产生新矛盾；
2. **路线失败**：某个联盟、方案或真相路线关闭，玩家必须换路径；
3. **终局失败**：午夜审计未归零、资不抵债、全面冻结或实际控制残留。

游戏应以 fail-forward 为主。行动失败不回到原点，而是留下费用、新闻、敌意、时间损失或新证据。
终局除了五个机械结局，还应生成三份遗产评价：

- 制度遗产：财富和权力最终去了哪里；
- 社会遗产：谁受益、谁承担代价；
- 人物遗产：关键人物如何评价玩家及其未完成关系。

## 12. 多人比较与重玩动力

排行榜不应只按“花掉金额”排序。建议比较：

- 是否真实归零；
- 控制权清除程度；
- 合规与系统连续性；
- 公共受益及代价分布；
- 发现的真相比例；
- 承诺履行率；
- 使用过的路线与制度遗产；
- 关键关系的最终状态。

重玩差异来自开局 seed、事件组合、人物秘密、市场与监管环境、玩家承诺和 Agent 自主行动，
不是简单提高数值难度。

## 13. 平台归属

| 系统 | Agent Hub / Organization Runtime | 通用能力包 | Speeding 包/应用 |
|---|---|---|---|
| Agent 身份、权限、工具 | 拥有 | — | 选择和绑定 |
| Run、状态、事件、预算、审计 | 拥有通用容器 | 声明 Schema/handler | 写领域数据和规则 |
| 人格底色 | 模板库和快照 | personality | 角色选择模板 |
| 情绪与关系动态 | 状态容器 | emotion/relationship-dynamics | 事件产生具体变化 |
| 群组、会议、工作流 | 拥有 | 模板 | 董事会、派系实例 |
| 世界实体与事实 | 只保存引用/审计 | belief 提供认知模型 | Speeding 拥有事实源 |
| 生存生命线 | 不理解字段 | 暂不抽通用包 | Speeding 世界规则 |
| 压力时钟、承诺锁、派系议程 | 提供事件与调度原语 | 第二个应用复用后再提炼 | Speeding 先实现 |
| 游戏虚拟时间 | 提供 Run/定时触发接口 | — | Speeding 拥有换算和 UI |
| 玩家动力、核心循环、结局 | — | — | Speeding 应用 |
| 事件内容与 Director | 受控注入接口 | narrative 可声明契约 | Speeding 内容与编排 |
| 排行榜与多人比较 | — | — | Speeding 应用 |

尤其需要坚持：压力时钟、承诺锁和派系议程虽然看起来可能通用，但目前先作为 Speeding 私有
机制实现。只有出现第二个真实垂直应用并验证相同语义后，才提炼为通用能力包，避免为了想象中
的通用性把 Agent Hub 做成游戏引擎。

## 14. 新增设计 TODO

- [ ] 明确玩家最终幻想：不是消费，而是设计自己的退场制度；
- [ ] 定义四条生存生命线及其失败/恢复规则；
- [ ] 定义短、中、长三层循环；
- [ ] 明确成功、代价成功、路线失败和终局失败；
- [ ] 建立一份“有趣决策”判断标准：至少两项不可兼得利益、一个延迟后果和一个人物立场。

### G1：可玩垂直切片

- [ ] 一个完整游戏日；
- [ ] 两项主要行动、一次调查、一次人物谈判；
- [ ] 三个压力时钟；

- [ ] 一个系统事件、一个路线事件、一个人物私事；
- [ ] 一项行动失败但故事继续；

- [ ] 连续性、程序、去权力三条主要治理路线；
- [ ] 每条路线的盟友、反对者、代价、锁定点和失败形态；
- [ ] 可混合路线，但不能无代价获取所有路线收益；

- [ ] 每日新局面与 seed 变化；
- [ ] 多维复盘、路线标签和玩家比较；
- [ ] 长局摘要、离线恢复和 Agent 调用预算。

## 15. 当前最需要先回答的设计问题

在大量编写事件之前，需要用垂直切片回答：

1. 玩家是在“优化五个指标”，还是在“选择自己认可的制度遗产”？后者应当主导体验。
2. 玩家每天为什么不能重复最优行动？必须由容量、审批、承诺锁、人物执行和世界反制回答。
3. 玩家失去正式权力后还能不能玩？建议进入代理、游说、披露和谈判阶段，而不是立即 Game Over。
4. 人物关系怎样改变玩法？必须改变信息、执行速度、可用工具或表决结果，不能只改变台词。
5. 真相线对归零任务有什么机械影响？应改变合法性、赔偿义务、人物联盟和结局评价。
6. 玩家如何感知因果？每次重大变化都要能追溯到行动、传播路径、规则和人物决定。

这些问题完成验证后，再批量生产 40 个以上事件，内容才不会变成昂贵但薄弱的分支文本。
