# ADR-0002：状态所有权、作用域与变更规则

- 状态：Accepted for H0
- 日期：2026-09-12
- 关联协议：`agenthub.extension/v1alpha1`

## 背景

平台既要承载通用情绪、任务状态，也要承载 Speeding 的财富、舆情等领域数据。若在
Agent 主表增加领域列，Hub 将被垂直应用绑死；若允许扩展任意覆写 JSON，又无法保证
权限、并发、幂等和复盘。

## 决策

采用“Core 托管、命名空间所有、Run 隔离”的通用状态模型。

- 状态地址为 `tenant + namespace + run + subject(type,id) + schema(version)`。
- Core 拥有存储、Schema 校验、租户隔离、乐观锁、幂等、审计与冻结。
- 声明 Schema 的能力包拥有字段语义、默认值、合法 reducer 和展示声明。
- 垂直应用拥有其命名空间的业务含义；例如 `com.speeding.world/*`。
- Agent/工具只能提交 proposal 或受限 patch；Core 验证权限与 revision 后 commit。
- 每次 commit 保存不可变的 `before / patch / after / reason / actor / source_event_id`。
- 一个命名空间默认不得读取或修改另一个命名空间；跨包访问必须在清单中声明并授权。

## 状态分类

| 类型 | 所有者 | 例子 | 是否按 Run 隔离 |
|---|---|---|---|
| 长期身份配置 | Hub | 名称、职责、工具授权 | 否 |
| 长期模板 | Hub/能力包 | 人格原稿、关系模板 | 否，运行时快照 |
| 通用动态状态 | 通用能力包 | 压力、信心、认知、主观记忆 | 是 |
| 垂直应用状态 | 应用能力包 | 财富、舆情、研究交付进度 | 是 |
| 静态关系合同 | Organization Runtime | 可发送动作、上下文策略 | 否，运行时快照 |
| 动态关系态度 | 关系动态能力包 | A 对 B 的信任、敌意 | 是且有方向 |

## 初始化与结束

- Run 启动时由锁定模板或 Schema 默认值初始化状态。
- 初始化事件也必须进入变更历史，不允许无审计的“初始写入”。
- Run 完成后状态冻结；可复制为新 Run 的初始化输入，但不得继续修改旧记录。
- 模板更新只影响之后启动的 Run。

## 明确不做

- Core 不认识 `stress`、`wealth` 等字段含义。
- UI Schema 不能授予写权限。
- LLM 不能直接提交最终状态快照。
- H0 不实现复杂表达式引擎，仅确定契约。
